# 补件与局部修形

参考方案只有在相同原画、相同动作输入的前后动态对照中改善观感，才能替换当前方案。无翻折、坐标误差小、静态九向正确都不等于脸部运动自然。观察脸颊、下巴与五官的相对关系是否随动作反复拉长、缩短或滑动；先隔离左右、上下转动，再检查正常速度下的组合。极限往复用于暴露问题，不能冒充日常展示，也不能只放慢录像掩盖变形。用户指出观感变差时，撤销此前的“通过”结论，保留失败候选作对照；不因已经投入开发或来源是参考项目就继续推为默认。

本方法只使用 `capabilities` 实际公开的 CLI，不内置模型调用。用户限制现有素材时只检查已有内容；已授权制作需要的补件由宿主当前可用的图像工具生成，不把特定供应商名称或机器路径当成能力保证。

## 参考与配准

先 `assets reference --project <目录> --layer <模板ID> --json`。返回的 cleanPath 是干净原素材，contextPath 是完整角色，annotationPath 标明原素材范围；标注图只用于说明，不能把框线生成到补件里。记录 reference ID、baseRevision、sourceRect 和画布。给生成器说明要保留的线稿、配色、接触阴影，以及这次真正需要改变的部分。

当前登记入口接受 PNG 并保留其 Alpha，不自动去除纯色底或棋盘格。优先要求真实透明 PNG；若宿主只能输出纯色底，先通过可用的确定性去底工具获得透明 PNG，再检查边缘。不能把“PNG 格式”或一张棋盘背景图当成透明成功。

生成器保留了声明画框时，用 frame 配准。generatedRect 是原始生成 PNG 中的内容框，sourceRect 是该框在原画布中的目标像素矩形；尺寸不同不等于目标角色需要缩放，非等比拉伸必须明确 allowStretch。生成器重新居中、旋转或改变留白时，用 landmarks 配准：在原始 PNG 与源画布中标记对应点，至少两点，优先根部、尖端和不共线的侧边第三点。查看 rmsErrorPixels；不要为了通过而放大容差。镜像必须明确 mirrorX/mirrorY，不能用翻转掩盖错误对应点。

调用 `assets register --project <目录> --reference <ID> --image <原始PNG> --registration <JSON> --json`。记录不可变 registration ID；调整位置时从同一原始 PNG 创建新配准，不反复缩放已处理结果。超出角色画布会被拒绝，不会自动裁掉素材。坐标统一按像素边界、左上原点、X 向右、Y 向下解释。

## 尽早试装再决定是否重画

用 assembly JSON 指定当前 baseRevision、additions（registrationId、未占用的 layerId，可选 name/order）和 replaceLayerIds。`assets preview --assembly <JSON>` 生成整个人物的前后姿态证据而不推进当前 revision；替换列表里的旧图层在候选中隐藏，不删除源图。新增图层继承模板的父级、部位响应和经空间重投影的关键形/权重，仍须实际看中性与转向画面。

先按正常观看尺寸看组合，再放大定位问题。位置、比例、旋转、镜像或留白不对时修配准；遮挡不对时修顺序或替换列表；根部漂移时查父级和局部固定权重；只有素材本身画错才重新生成。孤立部件很像原图不代表组合正确，隐藏区域的小差异也不自动构成返工理由。

试装成立后 `assets apply --plan <ID>`，它校验版本与素材哈希后通过现有校准事务写入。版本变化时重新准备参考和试装，不能手改旧计划的 baseRevision。查看实际 session 和证据，用户接受后才标 accepted；拒绝沿现有 history/restore 恢复。恢复保留原始 PNG、配准和历史，不手工删文件。

## 自然拆发

按发束走势、根部和前后穿插拆分，不把像素连通域直接等同于一束头发，也不为了绑定方便切成整齐条带。同一逻辑发束可能需要多个绘制片段才能表达交错遮挡；多个片段共用运动判断，不能给每块可见岛随机独立摆动。每束保留被遮挡处必要的连续体积，并保持原有接触阴影。

先装回完整角色检查轮廓、根部衔接和前后关系，再制作专属摆动。先验证自然组合成立，再调幅度和滞后；转动之后露出的缺口才是需要补画的证据。源 PSD 的整体结构已损坏时仍回到源图修复，不用大量补件遮住未知问题。

## 局部关键形

需要从原图定义眼睑或脸形目标时，先读 `shape-target-workflow.md`：用 `author inspect-shape` 核对坐标和像素职责，使用 `fit-landmarks` / `curve-warp` 制作目标，`author preview` 看标记、结果与中间姿态后再写入。已有区域平移、缩放与平滑仍按下述方法处理。

制作前先根据当前原画确定目标形状，再选择工具。眼部至少明确内外眼角、原眼线倾斜、睫毛尖端和厚度；左右眼分别判断，眼白、虹膜遮罩与睫毛共同闭合。优先从原眼部连续变形，用户要求原图变形时不能借闭眼补图替代制作。程序自动生成的曲线只是初稿；出现折角、眼角拉长、重影或眼线体量丢失，就继续修关键形，不以无翻折作为通过。三角形跨度无法承载曲线时，局部调整网格并保留原画 UV、已有权重和其它关键形，避免把网格外包络当成笔画。半闭、全闭、重新睁开分别检查，并在上下与左右转头时复核连接。

角色专属的眼角位置、曲线与脸部修形写入角色的关键形数据，通过 `author apply` / `calibrate` 保存；不把这个人物的数值加入通用默认值。头脸制作返回的 `measurements` 是观察数据，不能为了追求某个近远眼比例或下半脸伸缩比而强行修改原画。保持清楚的头脸、表情、物理职责，按实际目标修正，不因另一软件也采用某公式就默认接受。

完整头部九向关键形与程序化左右/上下转动是同一动作的两种来源，不能直接叠加。只有已经制作完整 yaw/pitch 关键形的图层，才在同一 `author apply` 事务中提交 `{ "op": "set-layer-head-pose", "layerId": "实际ID", "mode": "keyforms" }`；它关闭该层的程序化 yaw/pitch，保留 headRoll、表情、视线与次级运动。`mode: procedural` 恢复程序化路径，不删除关键形，因此恢复前也须处理同轴绑定，避免再次叠加。局部修形仍使用默认程序化路径，不因一个局部关键形就切换完整头部来源。

同层只保留一个完整 yaw/pitch 双参数头部绑定，表情先求值再随这个表面转动。补充张口图与备用闭眼图也要跟随同一脸部表面。合并同轴绑定前先查物理图：直接输入与延迟输出组成的惯性差值必须成对保留，不能因直接输入也是 yaw 就吞进造型。停止后检查两项抵消，运动中检查滞后。已有完整关键形时，通过 `author apply` 修改它，不能继续调用程序化头脸制作并把参数变化当成效果改善。闭眼必须检查中立和转头组合中的三角形方向，仅凭睁眼九向图或没有报错不足以通过。

参考的眼白闭合建立在规则列网格上，不能直接把同一细弧线压缩套到任意轮廓三角网。若中立闭眼已翻折，先处理眼白网格；通过现有 `calibrate` 每次修改一层，重投影该层所有关键形，再重建闭合端点。规则网格恢复原纹理坐标会改变原来的局部中立修形，必须对照睁眼原画和转头，不可声称外观完全不变。现有眼部制作会保留已有闭合绑定；修复时须明确 upsert 更新，不能只重跑制作命令。

转移已验证的同素材参考姿态时，按原画坐标和源网格三角形采样位移，保留中立网格，不能按顶点编号直接复制。完整头部位移写入后核对旧 yaw/pitch 绑定；兼容的纯几何增量应合并成一个清楚的主绑定，并检查端点及半程输出不变，不长期留下两组数值相互抵消。混有表情、物理、透明度或不同轴的绑定不能盲目合并。参考不存在的补充嘴形和闭眼图另行检查连接，不宣称它们也已经得到参考验证。

`author geometry --binding <ID> --values <按轴顺序的值> --revision <n> --offset 0 --limit 64` 按需分页；它返回实际三角网格或 warp 网格，nativeBezier 为 false。rest/position 是父级变换之前的归一化画布坐标，不能把屏幕截图坐标直接填进去。

通过 `author apply` 的 operations 提交 `transform-keyform`，明确 bindingId、已有关键形 values、coordinateSpace: rest-canvas、selection 和有序 transforms。选区支持 all、indices、rect、circle、line；柔化在选区内部发生，整个操作期间选区按中性几何固定。translate/scale/rotate/bend/smooth 的字段和单位见当前项目 `docs/AGENT_USAGE.md`；smooth 默认保留外轮廓与孔洞边界。保留当前稀疏增量，不反复累加同一旧指令。

缺少关键值时先使用 `insert-binding-key` 插入完整行/列，保持原插值再局部修改。结果仍须核对其他关键形、未点名区域、准确版本的静态与连续运动；工具调用成功不等于画面自然。接口超时后先读取 history 和当前 revision，确认是否已提交，再决定重试，不能盲目重放修改。
