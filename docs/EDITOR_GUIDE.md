# 校准编辑器说明

从首页的最近项目、项目目录选择器或创建结果打开绑定与校准编辑器。编辑器直接显示经过统一安全边界处理的 WebGL 合成，与验证、CLI 和透明角色窗口消费同一份项目语义。顶部显示当前 revision、绑定等级、图层数和实际安全系数，也可以直接“运行角色窗口”。

左侧是按当前绘制顺序排列的图层树。每层显示语义、侧别和顺序，并提供显示与锁定按钮；右侧还能修改父图层、运动归属、前后顺序、语义和侧别。父级关系会缩进显示，循环父级不会出现在候选项中。顶部四种模式分别处理脸部控制点、身体锚点、当前图层轴心/次级锚点和网格顶点。姿态按钮固定到中立、左右转、上下看和四个组合方向；“自主预览”恢复实际运行时间线。

右侧可以修改图层语义、侧别、父级、绘制顺序、可见性、锁定、运动归属，以及头部、身体、视线和次级运动的整层权重。网格密度可以按行列重建；重建会重采样权重并退出旧顶点编辑。网格模式选中顶点后，拖动使用可调半径的软选择，固定强度为 1 的点不会移动。逐顶点可以分别调节脸部控制笼、头骨控制笼、整体头部、身体、视线、次级运动和固定强度。

整体动作区调整安全包络、响应和稳定度；分部响应区分别调整前发、后发、呆毛、头饰、耳部、上衣、裙摆、尾巴和配饰的幅度、响应与稳定性。缺少某个分部覆盖时继续使用原有默认运动，不会因为新增字段改变旧项目表现。

拖动或调节后立即预览，并在 350 ms 静止后自动保存为草稿。控制点、锚点、轴心和网格顶点可用 Tab 聚焦，再用方向键以 `0.001` 步长微调，按住 Shift 为 `0.01`。返回主页或直接关闭窗口都会等待草稿写完；保存失败时窗口保持打开。重开同一项目后恢复草稿和校准说明。撤销和重做只影响本轮未提交修改。点击“保存校准”时，软件会等待在途草稿、验证调用方基线、坐标、关系、索引、13 个姿态和完整视觉证据；如果并发版本已变化、证据失败、绑定等级或安全系数变差则拒绝提交。成功后旧草稿自动失效并生成新 revision。

保存后的证据可以切换“修改前、修改后、分割、叠加、差异”，分割位置可调。历史区的任意会话都可以重新生成或加载相同证据，并标记为“确认”或“无效”；任意 revision 都能恢复成一个新的、可追踪的 revision。

“只恢复这个图层”清除该层的校准覆盖，其它已提交修改保持不变。“恢复全部自动绑定”会把 revision 0 的状态作为一个新修订保存；两者都不会删除旧历史。存在未提交草稿时这两个操作会拒绝执行，必须先保存或点击“放弃当前草稿”并确认。

控制点和网格不是越动越好。优先修连接关系和根部固定，再调作用权重，最后才移动个别网格点。大面积轮廓错误通常不是逐点拖网格能解决的，应检查语义、轴心或自动绑定算法。
