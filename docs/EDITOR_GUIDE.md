# 校准编辑器说明

从首页打开已有项目，或在创建完成后点击“打开绑定与校准编辑器”。编辑器直接显示当前修订的 WebGL 合成，不会另做一套与运行窗口不同的预览。

左侧是按原绘制顺序列出的图层。顶部四种模式分别处理脸部控制点、身体锚点、当前图层轴心/次级锚点和网格顶点。顶部姿态按钮固定到中立、左右转、上下看和四个组合方向；“自主预览”恢复实际运行时间线。

右侧可以修改图层语义与归属，以及头部、身体、视线和惯性的整层作用权重。网格模式选中一个顶点后，还可以单独设置它的五种权重：`pin` 固定根部，另外四项控制该顶点受对应运动的比例。全局动作区域只调整已经验证的动作范围、响应和稳定度，不改变素材内容。

拖动或调节后先在内存中预览。撤销和重做也只影响未保存修改。点击“保存校准”时，软件会验证坐标、索引和 13 个姿态；不安全的结果不会写入。保存成功后下方显示修改前后图，历史区出现新会话，可以标记“接受”或“拒绝”。

“只恢复这个图层”清除该层的校准覆盖，其它修改保持不变。“恢复全部自动绑定”会把 revision 0 的状态作为一个新修订保存；两者都不会删除旧历史。

控制点和网格不是越动越好。优先修连接关系和根部固定，再调作用权重，最后才移动个别网格点。大面积轮廓错误通常不是逐点拖网格能解决的，应检查语义、轴心或自动绑定算法。
