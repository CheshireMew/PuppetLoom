# 转头脸缘凹陷修复

用户指出，转头时屏幕左侧脸缘凹凸不平。隐藏头发后问题仍然存在，因此它是源项目变形的问题，不能归咎于 Cubism 导出或头发遮挡。此前导出一致性检查通过，只证明导出保留了源结果，不能作为脸形合格的证据。

## 原因与修改

旧 `semanticCageMapping` 在控制三角形内采用分片线性插值，超出范围后采用距离加权；两种计算在边界处不一致。三角形还接受 -0.015 的负重心坐标，导致相邻区域的选择包含重叠。实测猫耳角色左脸附近，两个距离不足百万分之一源图像素的位置，在 yaw=-1 / pitch=-1 时得到相差约 3.833 像素的结果。网格连接这些不一致的位移后，便出现折角、局部凹陷及形状突变。

现在区域内外统一采用薄板样条位移插值，保留控制点约束和仿射运动，消除区域分支切换。权重按源坐标缓存，局部关键形改变坐标时重新计算。重合或共线控制点无法求解时，整个区域统一使用连续的平滑权重，不在空间中切换算法。旧三角形插值与回退分支已移除。

该变化位于 PuppetLoom 共用的几何求值层，适用于桌面、离线渲染和 Cubism 导出；没有写入猫耳角色专用坐标，没有修改原图或通过缩小转头范围隐藏缺陷。它仍依赖人物的控制点与源网格质量，不能据此宣布任意人物造型均已通过。
