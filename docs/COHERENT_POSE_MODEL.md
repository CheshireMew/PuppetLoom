# 统一姿态模型

第三个演示项目没有公开源码，因此 PuppetLoom 没有复刻其内部代码。能从视频界面和成片确认的是：它把部件放入骨骼或运动组，用统一动作幅度、响应速度和稳定程度控制整套角色；脸部跟随同一个头部姿态，头发和身体再分组响应。基于这些可见事实，PuppetLoom 独立实现了下面这套适合自动绑定的模型。

## 一次姿态，分层响应

运行时只生成一组连续的头部 yaw、pitch 和 roll。脸部关键点确定一个椭球表面，脸、眼睛、眉毛、鼻子和嘴都在这个表面上投影。图层语义只决定相对深度和参与比例，例如鼻子略靠前、后发略靠后、耳朵与头部同步但保留较小弹性。它们不再分别进行没有共同结构约束的横向平移。

头部目标先经过二阶阻尼响应，避免观察动作瞬间开始或停止。视线会比头部提前，身体读取平滑后的头部结果并低幅延迟跟随。前发、后发、耳朵和饰品读取头部速度，各用不同刚度和阻尼产生二级运动；固定根部保持不动，自由端才获得较大位移。

```text
带种子的观察目标
  ├─→ 视线提前
  └─→ 阻尼头部姿态 ─→ 椭球姿态场 ─→ 脸 / 五官 / 耳朵 / 头发根部
                   ├─→ 延迟身体 ─→ 上身整体跟随
                   └─→ 头部速度 ─→ 前发 / 后发 / 耳朵 / 饰品惯性
```

## 自动生成与安全边界

姿态场中心和半径来自 PSD 的脸部关键点，不依赖当前角色的手工参数。中立状态严格返回原网格，因此不会改变 PSD 重组结果。创建阶段仍使用 13 个姿态检查网格翻转、严重拉伸、眼睛越界、脸发分离、颈部断开和画布越界；不安全时缩小动作或降为分组、最保守绑定。

这套实现采用了演示项目表现出的“共同姿态加分组响应”思路，但不包含其摄像头、MediaPipe、骨骼编辑器或任何未公开实现。PuppetLoom 当前把同一套驱动关系接到自主时间线，因为现阶段目标只是让角色合理地自己动。
