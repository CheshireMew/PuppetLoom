# 统一姿态模型

第三个演示项目没有公开源码，因此 PuppetLoom 没有复刻其内部代码。能从视频界面和成片确认的是：它把部件放入骨骼或运动组，用统一动作幅度、响应速度和稳定程度控制整套角色；脸部跟随同一个头部姿态，头发和身体再分组响应。基于这些可见事实，PuppetLoom 独立实现了下面这套适合自动绑定的模型。

## 一次姿态，分层响应

运行时只生成一组连续的头部 yaw、pitch 和 roll。脸部关键点确定脸部表面，头顶、下巴和脸宽共同确定更大的头骨表面。脸型、眼睛、眉毛、鼻子和嘴在脸部表面投影，头发、耳朵和头饰在头骨表面投影；两套表面先扣除各自的整体位移，再挂到同一个头部根节点上，因此头发可以改变轮廓而不会从脸上滑开。

左右眼不是等宽平移。转头时靠近观察者的一侧眼白、睫毛和眼角会略微变宽，远侧略微变窄；同一只眼的眼白、虹膜、睫毛和闭眼素材共用由眼白推导的眼眶中心，避免各层绕自己的包围盒中心缩放后在眼角露出白边。虹膜仍由对应眼白的 Alpha 区域裁切。视线先到目标，但随着头部完成转向会在眼眶内部分回中，避免眼球已经顶到一侧而脸仍像正面。脸层还会让远侧脸颊向内收、下巴随转向偏移；图层语义继续决定相对深度和局部参与比例，例如鼻子略靠前、后发略靠后、发梢比发根更自由。

头部目标先经过二阶阻尼响应，避免观察动作瞬间开始或停止。视线会比头部提前，身体再用一套响应更慢、阻尼更高的跟随器读取头部结果。呆毛、前发、后发、头饰、耳朵、衣摆、尾巴和饰品读取对应的头部或身体速度，各用不同刚度、阻尼、频率和相位产生二级运动。它们仍由同一条确定性时间线驱动，但不会在每一帧朝同一个方向摆动：静止观察阶段的前后发采用相反相位，呆毛随头发横摆，强力纵向弹动只在偶发事件中出现；头饰只做很小的整体回弹；合并在头饰图层里的两只耳朵平时保持中立，一次触发时各自围绕脸侧固定点连续快速抬落三至四次，同时允许很小的左右不对称；衣服跟随身体，尾巴最慢。固定根部保持不动，自由端才获得较大位移；关闭头部与身体主运动后，持续风动和按时间触发的局部事件仍然存在。

颈部不是整层平移。靠近下巴的上端完整继承头部连接位移，靠近衣领的下端逐渐切换为身体位移，因此头部先转、上半身随后跟进时，中间仍由连续变形的脖子连接，不会把整段脖子从衣领中拔出来。上衣、手臂和手的跟随幅度最大，裙摆次之，腿只保留很小的传递，脚保持落点。自主时间线也会交替安排横向观察、轻微低头和抬头，而不是把所有变化混在同一个斜向摆动中。

```text
带种子的观察目标
  ├─→ 视线提前
  └─→ 阻尼头部姿态 ─→ 共同头部根节点
                   ├─→ 脸部表面 ─→ 脸型 / 远近眼 / 眉毛 / 鼻口
                   ├─→ 头骨表面 ─→ 头发 / 耳朵 / 头饰
                   ├─→ 延迟身体 ─→ 上身整体跟随
                   └─→ 头部与身体速度 + 分相低频驱动
                                      └─→ 呆毛 / 前后发 / 头饰 / 耳朵 / 衣摆 / 尾巴 / 饰品惯性
```

## 自动生成与安全边界

两套表面的中心和半径都来自 PSD 的语义关键点，不依赖当前角色的手工参数。中立状态严格返回原网格，因此不会改变 PSD 重组结果。创建阶段仍使用 13 个姿态检查网格翻转、严重拉伸、眼睛越界、脸发分离、颈部断开和画布越界；不安全时缩小动作或降为分组、最保守绑定。

这套实现采用了演示项目表现出的“共同姿态加分组响应”思路，但不包含其摄像头、MediaPipe、骨骼编辑器或任何未公开实现。PuppetLoom 当前把同一套驱动关系接到自主时间线，因为现阶段目标只是让角色合理地自己动。
