# 第三个视频项目参考结论

复查对象是用户提供的本机视频 `40765424108-1-100026.mp4`。视频长约 64.3 秒、无音轨；下面只把画面中能直接看到的功能当作事实。项目没有公开源码，因此不能据此断言它内部具体使用了什么算法，也没有代码被复制到 PuppetLoom。

## 视频中能确认的机制

界面把工作流分为导入、拆分、绑骨、姿态、眨眼、口型、呼吸、预览和导出。姿态页提供头部/脸部、身体、前发和后发等语义模板；画布上能看到头顶、额头、双眼、脸侧、鼻子、嘴和下巴等标记点及连接线。该页还提供单项校准、左右转头、抬头/低头、自动巡检、穿帮修正、回到正面与作用图层确认。作用图层区会把 `head`、`face`、`eye_white`、`pupil`、`eyelash` 等实际图层列为候选。

预览页能看到摄像头驱动、快速校准、幅度、响应、稳定性、高级调节、诊断、动作组和 FPS。口型页展示了 THA3 生成 A/I/U/O 等嘴图的流程，后段使用 MediaPipe Face/Pose 做摄像头驱动；视频作者自己也把最终效果描述为尚不成熟。

## 对 PuppetLoom 有帮助并已采用的部分

| 视频中的可见思路 | PuppetLoom 的实现 |
| --- | --- |
| 用语义点描述角色结构 | 从 PSD 名称与实际 Alpha 自动定位 23 个脸部、眼角、嘴角、头骨和颈部点，不要求人工拖点 |
| 关键点之间形成姿态关系 | 生成脸部与头骨三角控制笼，让脸缘、眼角、鼻口、下颌、前发和头饰接受连续形变 |
| 单项校准后自动巡检 | 构建时先校验点位，再自动跑中立与 12 个运动姿态 |
| 穿帮修正 | 能由像素约束确定的问题会自动修点；网格仍不安全时依次缩小动作并降级绑定 |
| 确认作用图层 | `landmark-report.json` 明确列出脸部组和头骨组实际作用到的每个 PSD 图层 |
| 头脸、身体、前发、后发分组 | 共同头部姿态下使用不同局部权重、根部固定区、响应速度与二级惯性 |
| 幅度、响应、稳定性和性能诊断 | 保留统一运动调节参数、13 姿态报告、次级运动报告与 60 FPS 性能检查 |

这次迭代最重要的变化不是增加一个手工绑点界面，而是把“定位关键点、检查并修正、确认作用图层”变成 `create` 的自动阶段。Agent 可以直接读取构建报告和关键点报告；普通用户仍只需提供 PSD。

## 当前没有采用的部分

摄像头、MediaPipe 面捕和麦克风驱动不属于当前“角色自己合理地动”的目标，因此没有接入。THA3 的 A/I/U/O 口型也没有采用：当前只使用已经验收的自然闭口、微张和小幅张开三态，并由低频事件偶发开合。视频里的手工拖点、骨骼编辑器和逐项人工确认同样没有进入产品主链，因为它们会重新要求用户具备制作经验。

这些功能以后若重新进入范围，也应作为可选增强层，不应破坏“给一份分层 PSD，Agent 自动生成安全可动角色”的基础链路。
