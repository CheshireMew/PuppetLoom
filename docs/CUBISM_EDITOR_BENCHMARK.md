# Cubism 5.3 编辑体验对标

本次对标使用 Live2D 官方 Ren Foster 5.3 示例，分别检查建模、参数、动画和物理工作区。目的不是把 PuppetLoom 复制成另一个 Cubism，而是确认一个成熟可动角色工具必须让哪些关系可见、可调、可验证。

## 观察到的官方模型规模

Ren Foster 项目包含 51 个部件、198 个 ArtMesh、128 个 Warp Deformer、22 个 Rotation Deformer、7843 个顶点和 11041 个三角形。模型使用 8 组裁剪、20 处高级混合模式，以及 24 个离屏绘制部件；变形器嵌套评分为 893。运行时侧车包含 73 个参数、52 个 Part、5 个表情、16 组物理设置和 3 段循环动作。三段动作均为 60 fps，单段包含 68 条曲线，最长一段有 694 个曲线段和 1992 个控制点。

这些数字本身不是目标。重要的是它们在编辑器里被拆成了可以理解的结构：图层树负责素材与绘制关系，变形器树负责父子运动，参数面板负责可动范围，表情与动画时间线负责状态编排，物理面板负责输入、输出和延迟响应。

## 网格与结构

官方脸部 ArtMesh 沿下颌、鼻口和眼周轮廓布点，内部三角形围绕五官分布，而不是覆盖整个包围盒的长方形。网格只是最终结果的一部分；真正让它稳定的是上层变形器、参数关键形态、裁剪和绘制顺序。一个“看起来像 Cubism”的三角网，如果仍由每个图层独立平移，转头时照样会散架。

PuppetLoom 因此采用两层结构：渲染网格从真实 Alpha 提取独立区域和孔洞，内部用受约束三角剖分；脸部和头骨运动则来自共享语义控制笼与连续姿态场。完全不透明矩形仍允许保留紧凑规则网格。旧项目可从现有纹理非破坏式升级，生成结果先进入校准草稿，不覆盖自动绑定基线。

## 参数与姿态

Cubism 把 Angle X 与 Angle Y 组合成二维控制器，九个方向可以直接点击。参数按脸、眼睛、虹膜、眉毛、嘴和身体分组；当前值、范围和关键形态关系同时可见。相比之下，PuppetLoom 旧界面只有一排固定姿态按钮，用户看不到当前值，也无法单独检查视线、眨眼、口型或某个 authoring 参数。

新的“参数与姿态”工作区保留自动绑定定位，但补齐分组参数列表、九向二维头部控制器、单参数滑块、常用语义参数和表情混合。预览值不进入项目草稿，避免把验收操作误当成编辑。

## 表情、动画与物理

Cubism 的 Animation 工作区有场景列表、时间线、播放控制和分组轨道。官方示例的轨道按参数控制器、眨眼、口型、Live2D 参数、部件可见性、位置与透明度组织。Physics 设置则独立成完整窗口：每个物理组有输入与输出、影响度与反转、输入归一化、粒子链长度、摆幅、响应和收敛速度，并配有播放列表、实时粒子图、参数树与模型预览。

PuppetLoom 旧界面把这些概念缩成一个 `physics weight` 和几个整体滑块，既无法判断系统是否存在，也无法看到驱动关系。新的“表情与物理”工作区把具名表情、行为播放、分部次级运动和参数弹簧分开显示。没有 authoring 表情或行为的旧项目可以生成基础预览集；参数物理存在时可直接调输入输出缩放、响应和阻尼。PuppetLoom 的自动多段次级运动仍保留，因为它比要求用户手工搭每条粒子链更符合产品定位。

## 工作区与验收

Cubism 把 Modeling、Animation 和 Form Animation 作为不同工作区，并允许单独显示变形器、Inspector、参数、部件、项目、时间线和场景等面板。旧版 PuppetLoom 则把图层属性、网格、authoring 统计、整体动作、分部响应、保存和历史全部塞进一个右侧长栏，编辑画面和最终预览也没有分开。

新的桌面编辑器拆成五个工作区：

1. 项目总览：显示网格、语义、参数、动态系统和证据的实际完成度。
2. 结构与网格：处理图层层级、控制点、轴心、网格和权重。
3. 参数与姿态：直接检查参数范围与组合姿态。
4. 表情与物理：检查表情、行为、次级运动和参数弹簧。
5. 预览与验收：隐藏全部编辑标记，用固定姿态和多种背景检查最终呈现。

右侧属性在结构工作区进一步拆成图层、动作和版本三栏；左侧图层支持搜索，并可切换结构层级与绘制顺序。沉浸预览只保留最终角色和退出按钮，避免控制点、网格和长面板污染视觉判断。

## 仍然存在的边界

PuppetLoom 目前不准备实现 Cubism 的完整逐帧曲线编辑器、通用蒙版绘制器或任意离屏合成图。这些能力只有在自动生成结果无法通过真实角色验收，并且不能由现有 authoring 事务或 Cubism 导出桥接解决时才值得加入。下一轮判断应依据真实 PSD 的失败证据，而不是继续增加菜单数量。
